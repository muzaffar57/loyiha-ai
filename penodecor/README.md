# PenodecorPro — do‘kon (mobil)

Fasad bezaklari uchun mijoz sayti. Mavjud yuk tashish ilovasi (`webapp/`, `app/`) o‘zgartirilmagan.

## Ishga tushirish

```bash
cd penodecor
npm install
npm test
npm run dev
```

Sayt `http://localhost:5852` da ochiladi.

## Shu bosqichda nima bor

- Dizayn tokenlari va qayta ishlatiladigan komponentlar
- Mobil pastki menyu va katta ekran uchun yuqori menyu
- Bosh sahifa, katalog bo‘limlari, bo‘sh mahsulot holati
- Savatni brauzer xotirasida saqlash
- Mehmon profili, yetkazish, savol-javob, maxfiylik va shartlar
- O‘rnatish uchun web manifest

Mahsulot narxi, buyurtma yuborish va administrator paneli keyingi bosqich. Haqiqiy narx va telefon raqami kodga yozilmagan.
